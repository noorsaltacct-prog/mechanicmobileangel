# Mechanic Mobile Angel Website

Static, mobile-first website package built for GitHub and Vercel deployment.

## Included
- `index.html`
- `styles.css`
- `script.js`
- `assets/` with local logo and repair photos

## Business details used
- Business name: Mechanic Mobile Angel
- Phone: (747) 389-5386
- Area: Reseda, CA and surrounding areas
- Service positioning: 24/7 mobile mechanic service
- Services: oil changes, brake repairs, suspension work, timing chain replacements, water pump installations, complex engine repairs

## Notes
- The supplied service flyer image was **not** used in the website layout, per request.
- The quote form opens an SMS draft to the business number.
- No fake reviews, fake prices, or stock photos were added.

## Deploy on Vercel
1. Upload the contents of this folder to a GitHub repository.
2. Import the repository into Vercel.
3. Framework preset: `Other`.
4. No build command required.
5. Deploy.
